# HTMS Service Desk Capstone

This project is a capstone implementation for the LLM Application Engineering course.

The notebook demonstrates a Healthcare Technology Management Services (HTMS) service desk assistant that can classify and route user requests into appropriate categories such as:

- FAQ requests
- Service requests
- Escalations
- Safety-sensitive requests

The project also includes concepts covered throughout the course, including:

- Application architecture
- Prompting and routing
- Safety and guardrails
- Evaluation and golden sets
- Regression testing
- Cost, latency, and caching optimization

## Main Notebook

`HTMS_Service_Desk_Capstone_Final.ipynb`

## Project Goal

The goal is to build a reliable and structured LLM-based service desk assistant for Healthcare Technology Management Services.
